EVIDENCE BOUNDARY
Confiant directly analyzed the landing-page JavaScript, /config response,
ServiceWorker and SharedWorker flow. The published sample specifies a
665,136,399-byte pseudorandom component and shows the browser delivering the
assembled executable through a same-origin attachment path.

The query observes only a browser-created executable whose size is consistent
with that sample. It cannot prove that the browser assembled the file, that the
file contains malicious JavaScriptCore bytecode, that the user executed it, or
that SourTrade caused the event.
