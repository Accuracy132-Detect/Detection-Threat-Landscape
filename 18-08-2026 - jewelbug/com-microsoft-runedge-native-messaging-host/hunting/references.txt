Classification: Hunting query - Untested implementation sketch

Confidence: Medium
Primary platform: Microsoft Defender XDR
Required telemetry: DeviceRegistryEvents populated by Microsoft Defender for Endpoint

Evidence boundary
- Symantec directly reports that the Antino-delivered PDF Viewer extension used a Windows native-messaging helper registered under the misleading name com.microsoft.runedge and shows the exact Chrome registry path.
- The query identifies Registry events touching that exact key. It does not prove the referenced manifest or helper is malicious, that the browser extension was loaded, that commands executed, that data was exfiltrated, or that Jewelbug is responsible.
- RegistryValueData is projected for investigation but not filtered because the source does not publish its value. ActionType is also projected rather than filtered because supported values must be verified in the target portal schema.
