EVIDENCE BOUNDARY
StepSecurity statically compared malicious and clean package bundles and
detonated all six affected versions. The report documents a Node.js implant
that injects a self-reloading loader into @vscode/deviceid, Discord desktop
core, GitHub Desktop main.js and the global npm CLI.

The query surfaces Node.js-initiated DeviceFileEvents against those runtime
files. It does not prove file modification, malicious content, package import,
credential theft, persistence, C2 communication or campaign attribution.
