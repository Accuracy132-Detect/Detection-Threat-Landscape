Primary platform: Microsoft Defender XDR
Required telemetry: DeviceRegistryEvents populated by Microsoft Defender for Endpoint

Evidence boundary
- Acronis directly reports that PATCHCORD checks and writes the value BeaconBrowserHijack under HKCU\Software\Microsoft\Windows\CurrentVersion\Run, with its own executable path as data.
- The query identifies this exact campaign-specific persistence artifact. It does not verify the file behind RegistryValueData, browser-shortcut rewriting, successful execution, C2 communication or APT36 attribution.
- ActionType is projected for investigation but not filtered because supported values must be verified in the target portal schema.
